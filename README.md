# ebixIntro

**Insurance at ebix — Your plain-English guide to what we do and why.**

ebixIntro is a static internal reference site designed for insurance industry newcomers. It explains core insurance concepts (Life, Health, Annuities, Property & Casualty) in plain English, provides a searchable glossary of common terms, and includes an internal contacts directory.

## Quick Start

There is no build step. No npm. No dependencies. Just open the site in a browser.

### Option 1: Double-click

Open `index.html` directly in your browser. Everything works via `file://` protocol.

### Option 2: Local static server

If you prefer a local server (avoids any `file://` quirks):

```bash
# Python 3
python3 -m http.server 8000

# Then visit http://localhost:8000
```

Or use any static file server you like (VS Code Live Server, `npx serve`, etc.).
